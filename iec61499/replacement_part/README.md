# replacement_part/

`gripper.gcode` prints all the pieces of the replacement gripper in one job, on an Ender-3
S1 Pro with a 0.6 mm nozzle and PLA (0.15 mm layers, 14 m of filament). The slicer estimates
2 h 56 min; a trial print took 3 h 26 min.

The gripper is ["Parallel Gripper for EEZYbotARM MK2"](https://www.thingiverse.com/thing:4362304)
by sthone, licensed under the Creative Commons Attribution-NonCommercial license. The only
change made here is slicing the model into G-code. This file is distributed under the same
license, so, unlike the code of this repository, it **cannot be used commercially**.
